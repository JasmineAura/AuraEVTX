# AuraEVTX v0.3.1 · 星轨边框

- 统计区改为圆形刻度仪表，证据时间范围采用椭圆轨道。
- 内容区统一使用对称、小弧度的星象边框，随条目数量与窗口尺寸伸展，确保包含全部条目。
- 边框光弧缓慢巡行，刻度外环持续旋转；支持关闭动效及系统减少动态偏好。
- 导入按钮、搜索框和时区按钮采用胶囊轮廓，详情面板使用弧形转角。
- 更新界面演示截图，保留独立事件流的全宽阅读空间。

下载 ZIP 解压运行，或直接下载 EXE。需要 Windows 10/11 x64 和 WebView2 Runtime。发行包不包含日志或演示数据。

5 项浏览器交互测试通过，包含长列表在正常与最小窗口尺寸下完整位于边框内、边框确实移动、关闭动态后停止，以及系统减少动态偏好生效。
