# AuraEVTX v0.3.0 · 事件观测台

重新设计主界面与 README 封面，以克制的星图、天文钟和蓝金配色呈现本地日志调查。

- 去掉概览、统计、图鉴与列表的大块卡片边框，改为开放布局、细分隔与留白。
- 新增每秒走动的天文钟，支持实时、日志起点、日志终点及 UTC / 本地时间切换。
- 更新三套配色及明暗模式，动效可关闭；独立事件窗口继续保留全宽列表。
- 更新五张界面演示截图与简洁封面。

下载 `AuraEVTX-windows-x64.zip` 解压运行，或单独下载 EXE；需要 Windows 10/11 x64 和 WebView2 Runtime。

发行版不携带演示日志，日志分析在本机完成。常见事件释义按提供者、通道与 ID 区分，未收录的事件仍可完整浏览。

验证：3 项浏览器交互测试通过，覆盖时钟走时、证据时间与时区换算；另执行 Rust 测试和原生独立窗口验证。附件提供 SHA256SUMS.txt。
