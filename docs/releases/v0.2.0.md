## AuraEVTX v0.2.0

### 独立事件流

- 事件流改为独立桌面窗口，默认最大化，支持移动到第二块屏幕。
- 移除侧栏、概览区对事件列表的占位；仅在选中事件后展开详情，关闭详情恢复全宽。
- 主窗口可按日志来源、事件类型或分类打开独立窗口；重复打开会复用已有窗口。
- 主窗口与事件窗口同步主题、明暗模式、时间设置及工作区数据。
- 修复快速翻页时被初始搜索防抖重置回第一页的问题。

### 正式发行整理

- 移除样例入口、内置样例命令及样例打包资源，发行版为空工作区。
- README 新增界面截图、使用说明、开发构建说明及作者提供的微信打赏二维码。
- 新增 Windows 自动构建工作流，以及可检查产物内容的便携版打包脚本。
- 发布 EXE、便携 ZIP 和 SHA-256 校验文件。

### 下载

- **AuraEVTX-windows-x64.zip**：推荐，解压运行，包含使用说明。
- **AuraEVTX.exe**：独立可执行文件，方便直接下载运行。
- **SHA256SUMS.txt**：用于核对 EXE 和 ZIP 的 SHA-256。

运行环境：Windows 10/11 x64，需安装 Microsoft Edge WebView2 Runtime。软件不附带 EVTX 日志或数据库，不要求上传分析数据。

中文事件字典覆盖 136 条常见释义；未知提供者事件仍保留完整数据。日志级别不等于威胁等级，本版本尚未集成自动威胁检测。
