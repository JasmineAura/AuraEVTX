# AuraEVTX v0.3.2 · 日志卸载

已导入的 EVTX 现在可以单独从工作区卸载。

- 左侧日志列表增加卸载图标，概览“证据源文件”增加“卸载日志”。
- 独立事件窗口选定来源后可“卸载当前日志”。
- 确认后在同一事务内移除对应事件、收藏和文件索引，原始 EVTX 保留，其他文件不受影响。
- 主窗口与事件窗口同步刷新；已移除来源的筛选、页码和事件详情自动复位。
- 已卸载文件可再次导入；导入与卸载互斥，避免并发修改。

下载 ZIP 解压运行，或下载单独 EXE。需要 Windows 10/11 x64 和 WebView2 Runtime。

验证：6 项浏览器交互测试、2 项基础 Rust 测试通过；真实 EVTX 完成导入、卸载与重新导入，原始文件内容保持一致。
