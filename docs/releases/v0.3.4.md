# AuraEVTX v0.3.4 · 事件检索与分类修复

- 修复事件分类仅显示前 6 类的问题：全部分类自动换行显示，“审计”“其他”等分类不再被截掉。
- 主搜索直接检索事件 ID，不再依赖 ID 是否出现在 XML 或摘要中；同时支持通道与分类文本。
- 增加 `id:4719` / `eventid:4719` 精确查找，避免混入字段值中包含同号数字的记录。
- 若当前来源、分类、时间、级别或收藏筛选导致无结果，可保留关键词“一键在全部日志中搜索”。
- 修复最后一页收藏被取消后仍停在空白页的问题，自动回到有效页码。
- 完善 Security 通道 4719“系统审核策略变更”的说明、微软参考链接和操作主体/审核策略变更字段摘要；已有索引启动后更新释义，字典总数仍为 141。

原始 EVTX、字段、XML 与收藏保持不变，无需卸载重新导入。

下载 ZIP 解压运行，或下载单独 EXE。需要 Windows 10/11 x64 和 WebView2 Runtime。

验证：9 项浏览器交互测试、5 项基础 Rust 测试通过，覆盖 10 种分类、未收录事件、普通/精确 ID 搜索、筛选恢复、SQL 参数与通配符转义、CSV 一致性及 4719 解析。
